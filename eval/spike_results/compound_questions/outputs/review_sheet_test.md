# Review sheet: split audit questions (blind)

Reviewer: you did not write these and have not seen the machine checks. For each row, read the source quote, then today's question, then the proposal.

Grade two things. Leave notes if unsure.

- **Faithful**: does the proposal ask for exactly what the source quote requires? `Y` = yes, nothing dropped, added or made stronger or weaker (may/should/must, conditions, numbers, who acts). `N` = something is dropped, added, hedged or changed. `?` = cannot tell.
- **Easier**: would an auditor find it easier to check than today's single question? `Y` / `N` / `same`.
- An invented 'as appropriate' / 'as required' counts as N for Faithful. A part that is only filler counts as N for Easier.
